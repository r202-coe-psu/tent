## #2 [Station 1] ค้นหาด้วยเบอร์โทรแล้วไม่เจอครัวเรือน
**Labels:** bug, station-1 · **ผู้รับผิดชอบ:** คน A · **กำหนด:** 5/10 · 🔴

**ปัญหา (Flow 1)**
- staff พิมพ์เบอร์โทรเพื่อหาครอบครัว แต่ไม่ขึ้นครัวเรือน

**สาเหตุในโค้ด (มี 2 จุด)**
1. ช่องค้นหาหน้า Station 1 (`src/lib/features/people/ui/search-scan/station1-intake-search.svelte` ~81–98)
   - ค้นใน CouchDB ผ่าน `matchesEvacueeSearch` (`src/lib/features/people/domain/people.ts` ~1986–2012)
   - จับคู่เฉพาะ `evacuee.phone` ของแต่ละคน — **ไม่ดู `emergency_contact.phone`**, ไม่แปลง `+66` → `0`
   - สมาชิกที่ติ๊ก "ไม่มีเบอร์" มี `phone = null` → ค้นด้วยเบอร์ของคนอื่นในบ้านไม่เจอคนนั้น
   - ผลลัพธ์เป็น "รายคน" ไม่ใช่ "ครอบครัว"
2. ช่อง "ค้นหาครอบครัวด้วยเบอร์โทรศัพท์" ในฟอร์ม `/onsite/people/new`
   (`src/lib/features/people/ui/registration/unified-registration-form.svelte` ~991–1042, state `searchPhoneQuery` ~233)
   - แสดงบน Station 1 ด้วย แต่ **ใช้งานจริงเฉพาะ public** (~339–416)
   - ฝั่ง onsite แนะนำครอบครัวจากที่อยู่เท่านั้น (~289–336) → **ช่องนี้บน Station 1 ไม่ทำอะไรเลย**

**สิ่งที่ต้องทำ**
- [ ] normalize เบอร์ฝั่ง frontend ให้เหมือน backend (`backend/apiapp/utils/masking.py` `normalize_phone`: ตัดขีด/ช่องว่าง, `+66` → `0`)
- [ ] ค้นเบอร์ใน `phone` และ `emergency_contact.phone` ของสมาชิก
- [ ] ผลค้นหาด้วยเบอร์ ให้แสดงครอบครัวที่คนนั้นอยู่ (ชื่อหัวหน้าครอบครัว + จำนวนคน) — ใช้ต่อใน #20
- [ ] ช่องค้นหาด้วยเบอร์ในฟอร์ม onsite: ทำให้ทำงาน (ค้น household จากเบอร์) **หรือ** ซ่อนบน Station 1 แล้วให้ไปค้นจากหน้า #20 แทน — ตกลงกับ #20
- [ ] unit test `matchesEvacueeSearch`: เบอร์มีขีด, `+66`, เบอร์ผู้ติดต่อฉุกเฉิน, สมาชิกไม่มีเบอร์

**เสร็จเมื่อ**
- ค้นด้วยเบอร์ของสมาชิกคนใดคนหนึ่ง (ทุกรูปแบบการพิมพ์) แล้วเจอครอบครัวนั้น
- ไม่มีช่องค้นหาบน Station 1 ที่กดแล้วไม่เกิดอะไรขึ้น
- `pnpm test` ผ่าน

## #20 [Station 1] หน้าเริ่มต้น: "ครอบครัวเคยลงทะเบียนแล้ว" หรือ "ลงทะเบียนใหม่"

  (pre-register, สแกนที่ตู้ Kiosk, หรือมาถึงศูนย์ก่อน) → เกิดครอบครัวซ้ำ (#1)
- join คนที่ลงทะเบียนผ่านตู้ไม่ได้ เพราะไม่มีปุ่มค้นหาครอบครัว (#3)
- การ merge จาก pre-register ดูเหมือนลงทะเบียนทั้งบ้านใหม่อีกรอบ จิตอาสางง (#12)
- การ join ครอบครัวตอนนี้ซ่อนอยู่ในฟอร์ม: ระบบแนะนำจากที่อยู่ แล้วให้กด "เข้าร่วม" / "สร้างใหม่"
  (`unified-registration-form.svelte` ~1161–1201) — ถ้าไม่เห็นหรือไม่กด ระบบสร้างครอบครัวใหม่

**สิ่งที่ต้องทำ**
- [ ] ก่อนเข้าฟอร์ม Station 1 แสดงหน้าเลือก 2 ทาง เป็นการ์ด/ปุ่มใหญ่ มีไอคอน + คำอธิบายภาษาง่าย:
  - **"ครอบครัวนี้เคยลงทะเบียนแล้ว"** — "มีคนในครอบครัวลงทะเบียนล่วงหน้า สแกนบัตรที่ตู้ หรือมาถึงศูนย์ก่อนแล้ว"
  - **"ลงทะเบียนครอบครัวใหม่"** — "ยังไม่มีใครในครอบครัวลงทะเบียน"
- [ ] ทาง "เคยลงทะเบียนแล้ว":
  - ช่องค้นหาช่องเดียว (เลขบัตร / เบอร์โทร / ชื่อ) — ใช้ของเดิมใน `station1-intake-search.svelte` (+ ผลจาก #2)
  - ผลลัพธ์แสดงเป็นครอบครัว: ชื่อสมาชิกที่มีอยู่ + จำนวนคน + มาจากไหน (ลงทะเบียนล่วงหน้า / ตู้ / ในศูนย์)
  - ปุ่ม "เลือกครอบครัวนี้" → เข้าฟอร์มแบบเพิ่มสมาชิกเข้าครอบครัวนั้น (ตั้ง `joinHouseholdId` ให้เลย)
    หรือ report-in ถ้าเป็น pre-register
    พร้อมแถบบอกชัดว่า "กำลังเพิ่มสมาชิกเข้าครอบครัวของ ___" และข้อมูลเดิมแสดงแบบอ่านอย่างเดียว
  - ไม่พบ → ปุ่ม "ไม่พบครอบครัว ลงทะเบียนใหม่" ไปทางที่ 2 ได้ทันที

- [ ] ทุกหน้ามีปุ่ม "ย้อนกลับ" กลับไปหน้าเลือก 2 ทางได้

## #1 [Station 1] ลงทะเบียนแล้วเกิดครอบครัวซ้ำ
