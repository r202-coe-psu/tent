- (decision) Deliverable scope is solely ARCHITECTURE-SPINE.md as a build substrate for developers and AI agents
- (decision) System adopts Two-Plane Data Architecture: Staff SoR plane (CouchDB) and Public read-model plane (MongoDB + FastAPI)
- (decision) Third-party agencies integrate via FastAPI external endpoints (/external/v1/*) authenticated by scoped API tokens/keys (X-API-Key with verified scopes)
- (decision) Remote-First Policy: Direct HTTP mutation to active endpoint (1. Central CouchDB -> 2. LAN Edge fallback -> 3. Disconnected status-only banner with 3 auto-retries + force retry); strict zero PouchDB and zero client-side write queue
- (decision) Frontend adopts Feature-Sliced Clean Architecture strictly enforcing ui -> application -> data -> domain dependency direction exposed solely via index.ts barrel with ESLint no-restricted-imports
- (decision) Public Plane Security: Browser SPA accesses FastAPI via SvelteKit BFF routes (/api/public/v1/*) authenticated with Bearer EXTERNAL_API_SECRET; direct browser-to-FastAPI access is blocked
- (decision) Database Partitioning: Multi-database isolation with shelter_{code} for shelter operations, central_ops for cross-tenant referrals, registry for system master data, catalog for global resources, and _users for auth
