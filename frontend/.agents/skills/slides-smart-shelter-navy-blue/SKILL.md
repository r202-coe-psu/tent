# Slides — Smart Shelter Navy Blue

ตีมกลางของคู่มือผู้ใช้ PSU Smart Shelter ให้ทุกเล่ม (คลัง, ตั้งค่าศูนย์, เพิ่มเจ้าหน้าที่, บริจาค, ลงทะเบียน, …)
ดูเป็นระบบเดียวกัน. มี 2 ทางใช้: **A) สร้างสไลด์ใหม่** ตามสเปกด้านล่าง, **B) refactor ไฟล์ .pptx เดิม** ด้วยสคริปต์ใน `scripts/`.

### Layout 3 แบบ (custom layouts ใน master)
- **Cover** — พื้น navy เต็ม: โลโก้บนป้ายสี่เหลี่ยมมนสีขาว (ซ้ายบน), แถบ cerulean เล็ก, ชื่อคู่มือ 96pt bold ขาว,
  subtitle `PSU Smart Shelter` 72pt bold `#BFD4F2`, คำอธิบาย 24pt, บรรทัดฉบับ `ฉบับที่ 1.0  •  <วันที่ไทย พ.ศ.>` 20pt, เลขหน้า
- **Content – Band** — แถบ navy สูง **0.95 นิ้ว** ด้านบนมี title 36pt bold ขาว (บรรทัดเดียว, ลดได้ถึง 24pt), พื้น `#F8FAFC`, เลขหน้าขวาล่าง 16pt
  - **ห้ามมี** แถบสี/เส้นขีดใต้หัวข้อ, **ห้ามมี** footer ใด ๆ
  - พื้นที่เนื้อหา: x 0.6–19.4, y 1.35–10.55 นิ้ว
- **Section** — สไลด์แบ่งตอน: พื้น navy เต็ม ข้อความขาว เลขหน้า

### เลขหน้า
ต้องเป็น **slide-number field จริง** (`<a:fld type="slidenum">` ใน placeholder `sldNum` idx 12) เป็นตัวเลขล้วน ขวาล่างทุกหน้ารวมปก.
ห้ามพิมพ์เลขเป็นข้อความธรรมดา.

### กฎเนื้อหาสไลด์ (ให้อ่านออกแม้ฉายบนจอเล็ก)
- ขนาดตัวอักษรเนื้อหา **≥ 24pt** (ขั้นตอน 26–30pt); ต่ำกว่า 18pt เฉพาะหน้าแน่นมากที่เลี่ยงไม่ได้
- หน้า screenshot: ใช้**รูปต้นฉบับ** ครอปขอบว่างทิ้ง แล้วขยายให้ใหญ่ที่สุดเท่าที่พื้นที่เอื้อ (ข้อความใน UI ต้องอ่านออก); วางรูปข้างข้อความ (A) หรือรูปบน-ข้อความล่าง (B)
- ป้ายตัวเลข/กรอบแดงที่วางทับรูปต้องย่อ-ขยาย**ไปพร้อมรูป** (scale เท่ากัน)
- หน้าการ์ดหลายคอลัมน์: เลือก preset ขนาดตัวอักษรให้การ์ดไม่ล้น (32/28 → 24/18)
- 1 สไลด์ = 1 หัวข้อ; ไม่ใช้ภาพพื้นหลังหรือของตกแต่งที่กินพื้นที่เนื้อหา

## 2. ทาง A — สร้างสไลด์ใหม่

1. เริ่มจากไฟล์ .pptx ที่ refactor แล้ว (ทาง B) เป็น template หรือสร้างด้วย python-pptx แล้วใช้ layout ชื่อ `Cover`, `Content – Band`, `Section`
2. ใส่ข้อความใน placeholder ของ layout (ไม่สร้างกล่องข้อความทับ) เพื่อให้ฟอนต์/สี/เลขหน้ามาจาก master
3. ปกแก้เฉพาะ: ชื่อคู่มือ (`คู่มือ…`), บรรทัดคำอธิบายกลุ่มผู้ใช้ 1–2 บรรทัด, วันที่/ฉบับ
4. ตรวจด้วย LibreOffice render (ดู §4) ก่อนส่ง

## 3. ทาง B — refactor deck เดิม (`scripts/`)

ต้องมี: Python 3 + `python-pptx`, `lxml`, `pillow`; ฟอนต์ **Prompt** (Regular + Bold) ติดตั้งในเครื่อง (หรือตั้ง `SS_FONT_DIR`);
`soffice` + `pdftoppm` สำหรับตรวจ.

```bash
uv venv venv && uv pip install --python venv/bin/python python-pptx lxml pillow
cd scripts
PYTHONPATH=. ../venv/bin/python -s themer2.py <input.pptx> <output.pptx> <config.json>
python cmpall.py <input.pptx> <output.pptx> <config.json>     # เทียบข้อความกับต้นฉบับ
```

- ต้องรันผ่าน `themer2.py` (มันโหลด `themer.py` เป็นฐาน) และใช้ `PYTHONPATH=. … python -s` (อย่าใช้ `-I` เพราะ import ในโฟลเดอร์ไม่ได้)
- โลโก้ปกอยู่ `assets/logo.png` (เปลี่ยนด้วย env `SS_LOGO`)
- ไม่แก้ไฟล์ต้นฉบับ — เขียนไฟล์ใหม่เสมอ (แนะนำโฟลเดอร์ `themed/`)

### สิ่งที่สคริปต์ทำให้
เขียน theme (สี `SmartShelter Navy`, ฟอนต์ `SmartShelter Prompt`) + layout ใหม่, ย้ายทุกสไลด์เข้า layout, สร้างปกเป็นสไลด์แรก,
แปลงสีตกแต่งเป็นโทน navy, ตัดฟอนต์ฝังอื่นทิ้ง, ลบแถบ/ของตกแต่งเดิม (แถบข้าง, เส้นบาง, สี่เหลี่ยมเต็มจอ, footer),
ยกหัวข้อไปไว้ในแถบ navy, ครอป-ขยาย screenshot (ครอปพิกเซลจริง) พร้อม overlay, ปรับขนาดตัวอักษรตามพื้นที่, แปลงสไลด์พื้นเข้มเป็น Section,
ใส่เลขหน้าเป็น field.

### Config (`<deck>.json`) — ตัวอย่างอยู่ใน `examples/`

```json
{
  "cover": {
    "title": ["คู่มือระบบคลัง"],
    "subtitle": "PSU Smart Shelter",
    "desc": ["บรรทัดที่ 1", "บรรทัดที่ 2"],
    "edition": "ฉบับที่ 1.0  •  13 พฤศจิกายน 2569"
  }
}
```

| key | ความหมาย |
| --- | --- |
| `cover.title` | list ของบรรทัด (หลายบรรทัดถูกต่อเป็นบรรทัดเดียวเมื่อพอดี; ขนาดลดอัตโนมัติ) — **จำเป็น** |
| `cover.subtitle` / `desc` / `edition` | ตามตัวอย่าง; `desc: []` = ไม่มีบรรทัดคำอธิบาย |
| `delete_slides` | เลขสไลด์ (นับจาก 1 ในไฟล์เดิม) ที่ลบทิ้ง เช่น สไลด์ว่าง |
| `delete_text` | `{"8": ["ข้อความที่ขึ้นต้นด้วย…"]}` ลบกล่องข้อความที่ผู้ใช้สั่งให้ลบ |
| `notitle` | สไลด์ที่ไม่มีหัวข้อแยก (แถบ navy ว่าง) |
| `light_slides` | สไลด์ที่ใช้พื้นอ่อนแทนการแปลงเป็น Section (พื้นเข้มเดิมแต่ต้องการ template ปกติ) |
| `strip_footer` | ลบ footer เดิม/กล่องเลขหน้าที่พิมพ์เอง (ค้นรวมในกลุ่ม) |
| `nested_title` | หัวข้ออยู่ในกลุ่มซ้อน (deck แบบ d5) |
| `no_plan` | ข้ามตัวจัดวางรูปอัตโนมัติ (หน้าแน่น/โครงซับซ้อน คงองค์ประกอบเดิม) |
| `free_sizes` | ไม่ล็อกขนาดตัวอักษรเดิมของสไลด์ที่มีรูป |
| `color_map` / `light_map` | แมปสี hex เพิ่ม (`{"0F766E":"0A2647"}`); `light_map` แทนที่ชุดสีของ `light_slides` |

**หมายเหตุ:** `delete_slides`/`delete_text`/`notitle` ใช้เลขสไลด์ของ**ไฟล์ต้นฉบับ** (ปกเดิมคือสไลด์ 1 ซึ่งถูกแทนที่ด้วยปกใหม่)

## 4. ตรวจสอบก่อนส่ง (บังคับ)

1. **ข้อความต้องไม่เปลี่ยน** — รัน `cmpall.py` ต้องรายงาน `slides with text differences: 0` ยกเว้นที่ผู้ใช้สั่งลบ/ปกที่เปลี่ยนตามตกลง.
   ห้ามแก้คำผิด/ตัวสะกดในเนื้อหา — รายงานให้เจ้าของเนื้อหาแทน
2. Render ดูจริง: `soffice --headless --convert-to pdf out.pptx` แล้ว `pdftoppm -r 50 -png out.pdf pg` ทำ contact sheet ดูทุกหน้า
   หา: ข้อความล้น/ซ้อนรูป, รูปบีบเบี้ยว, หัวข้อ 2 บรรทัด, แถบว่าง
3. ยืนยันว่ามีเลขหน้าทุกหน้า, ไม่มี footer, ฟอนต์เป็น Prompt เท่านั้น
4. แจ้งผู้ใช้ว่า render ตรวจด้วย LibreOffice (ไม่ใช่ PowerPoint) และเสนอให้เปิดใน PowerPoint ตรวจซ้ำ

## 5. ข้อควรระวัง / ที่เคยพลาด

- **อย่าครอปรูปด้วย `srcRect`** ของ shape แบบ freeform — LibreOffice ไม่รองรับ รูปจะบีบเบี้ยว สคริปต์ครอปพิกเซลจริงแล้วฝังรูปใหม่ (`get_or_add_image_part` + `drop_rel`)
- ภาพหน้าจอใน deck เดิมเป็น **picture-filled freeform** ไม่ใช่ `p:pic` — โค้ดที่ค้นเฉพาะ `p:pic` จะหารูปไม่เจอ
- ข้อความไทยตัดบรรทัดยาวกว่าที่ประมาณ: โค้ดคูณ safety factor (Regular ×1.14, Bold ×1.04) — อย่าลดโดยไม่ render เทียบ
- สีขาวบนพื้น navy กลายเป็นมองไม่เห็นถ้าแมปสีกว้างเกินไป (กรณี d5 สไลด์ 37) — ใช้ `light_map` จำกัดเฉพาะสีที่ต้องเปลี่ยน
- หัวข้ออยู่ในกลุ่มซ้อน / footer อยู่ในกลุ่ม → ตั้ง `nested_title` / `strip_footer`
- หน้าที่หัวข้อเป็นบรรทัดแรกของเนื้อหา (ไม่มีกล่องหัวข้อ) จะได้แถบ navy ว่าง — ตัดสินใจแล้วให้**คงแถบว่าง** (ไม่ยกข้อความขึ้นเป็นหัวข้อ เพราะห้ามแก้เนื้อหา)
- เลขลำดับรายการ `1. 1. 1.` ซ้ำใน LibreOffice เป็นพฤติกรรมเดิมของต้นฉบับ ไม่ได้เกิดจากสคริปต์
- การเปลี่ยนเนื้อหา/ลบสไลด์/ลบรูปที่ผู้ใช้ไม่ได้สั่ง = ต้องถามก่อน (เช่น รูป Discord ที่ไม่เกี่ยวใน deck คลังสไลด์ 8: ลบเฉพาะข้อความ รูปคงไว้และรายงาน)
